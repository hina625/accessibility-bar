Accessibility Bar Embed

To embed the Accessibility Bar on your website, add this script tag before the closing </body> tag:

<!-- Accessibility Bar Embed -->
<script src="https://your-domain.com/embed-standalone.js"></script>

Or use the local file:

<!-- Accessibility Bar Embed (Local) -->
<script src="./public/embed-standalone.js"></script>

Example Usage:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>
<body>
    <h1>Welcome to My Website</h1>
    <p>Your content here...</p>

    <!-- Embed Accessibility Bar -->
    <script src="./public/embed-standalone.js"></script>
</body>
</html>

Build the Embed:

First, build the embed bundle by running:

npm run build:embed

This will create the embed-standalone.js file in the public folder.
